# Неон-брейкер

Арканоид на Canvas в одном файле: платформа, мяч, кирпичи с несколькими ударами прочности и бонусы.

## Как играть

Открой `index.html` в браузере — или включи GitHub Pages в настройках репозитория
(Settings → Pages → Branch: main, папка `/root`).

- Веди платформу пальцем по экрану или стрелками ←/→ (A/D, Ф/В)
- Тап / Enter / пробел — запустить мяч
- P или ⏸ — пауза, 🔊 — звук

## Бонусы из кирпичей

| Знак | Что делает |
|:---:|---|
| W | Платформа шире на 12 секунд |
| M | Мультимяч: до 4 дополнительных мячей |
| S | Замедление мячей |
| ♥ | +1 жизнь |
| + | +250 очков |

## Уровни

Каждый уровень добавляет ряды и скорость мяча, у кирпичей растёт прочность (до 4 ударов).
За зачистку уровня +100 очков. Рекорд хранится в localStorage.
